# saes-standard-private
Master instructions for building reliable, secure, maintainable, and testable software without wasting time or damaging existing work.

## Repository contents

- [README.md](README.md) – project overview
- [REQUIREMENTS.md](REQUIREMENTS.md) – requirements and planning guide

- [CHECKLISTS.md](CHECKLISTS.md) – quality and release checklists
- [docs/](docs/) – optional project documentation directory

## GitHub Pages

This repository is suitable for static documentation hosting via GitHub Pages. To enable it:

1. Open repository Settings
2. Go to Pages
3. Select the `main` branch and root folder
4. Save the configuration

The site will be published under the repository's GitHub Pages URL.
